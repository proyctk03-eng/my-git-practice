    Khởi động MySQL Workbench, tại ngăn Navigator bên trái, nhấp chuột phải vào schema student-management và chọn Create Table...

  2. Bước 2: Cấu hình bảng Class

    Đặt Table Name là Class. Trong bảng danh sách cột bên dưới, điền 2 trường:

  3. Bước 3: Xác nhận Apply để tạo bảng Class

    Lặp lại các bước trên: Nhấp chuột phải vào schema chọn Create Table, đặt tên Teacher và khai báo 4 trường: id (INT), name (VARCHAR 200), age (INT), country (VARCHAR 50). Sau đó nhấn Apply.

📜 Kịch Bản SQL Đầy Đủ (01_create_schema_and_tables_basic.sql)

SQL Script 
-- 1. Khởi tạo CSDL student-management
CREATE DATABASE IF NOT EXISTS `student-management`;
USE `student-management`;

-- 2. Tạo bảng Class (Lớp học)
CREATE TABLE IF NOT EXISTS Class (
    id INT,
    name VARCHAR(200)
);

-- 3. Tạo bảng Teacher (Giảng viên)
CREATE TABLE IF NOT EXISTS Teacher (
    id INT,
    name VARCHAR(200),
    age INT,
    country VARCHAR(50)
);

-- 4. Bảng Student tích hợp
CREATE TABLE IF NOT EXISTS Student (
    id INT,
    name VARCHAR(200),
    age INT,
    country VARCHAR(50)
);

-- 5. Kiểm tra danh sách bảng
SHOW TABLES;

🚀 Kịch Bản Mở Rộng Quan Hệ (03_create_tables_advanced_relational.sql)

Mô hình quan hệ chuẩn hóa 3NF có khóa chính (PRIMARY KEY), khóa ngoại (FOREIGN KEY) và ràng buộc toàn vẹn:

Relational SQL Script 
USE `student-management`;

CREATE TABLE IF NOT EXISTS Teacher_Advanced (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    age INT NOT NULL CHECK (age >= 21 AND age <= 70),
    country VARCHAR(50) NOT NULL DEFAULT 'Vietnam'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS Class_Advanced (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL UNIQUE,
    teacher_id INT,
    CONSTRAINT fk_class_teacher FOREIGN KEY (teacher_id) 
        REFERENCES Teacher_Advanced(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS Student_Advanced (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    age INT NOT NULL,
    country VARCHAR(50) NOT NULL,
    class_id INT,
    CONSTRAINT fk_student_class FOREIGN KEY (class_id) 
        REFERENCES Class_Advanced(id) ON DELETE RESTRICT
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
