Luyện tập toàn diện các thuộc tính định kiểu cho danh sách HTML: list-style-type, list-style-image, list-style-position, list-style shorthand, màu sắc và khoảng cách.

Mục 2

Danh sách không thứ tự (list-style-type: square)

Danh sách các môn học sử dụng thẻ <ul> với kiểu đánh dấu hình vuông square:

  • HTML
  • CSS
  • JavaScript
  • Git
Mục 3

Danh sách có thứ tự (list-style-type: upper-roman)

Danh sách các bước học sử dụng thẻ <ol> với kiểu đánh số La Mã viết hoa upper-roman:

  1. Học HTML
  2. Học CSS
  3. Học JavaScript
  4. Học Git
Mục 4

Sử dụng hình ảnh làm dấu đánh dấu (list-style-image)

Danh sách các công cụ học tập sử dụng hình ảnh biểu tượng tùy chỉnh qua url('bullet.png'):

  • Visual Studio Code
  • Google Chrome
  • GitHub
  • Git
Mục 5

Thay đổi vị trí dấu đánh dấu (list-style-position)

So sánh trực quan hai danh sách có đường viền để thấy rõ dấu đánh dấu nằm ngoài (outside) hay nằm trong (inside) hộp nội dung:

1. list-style-position: outside (Mặc định)

Dấu đánh dấu nằm bên ngoài lề nội dung của thẻ <li>:

  • Visual Studio Code - Trình soạn thảo mã nguồn mạnh mẽ
  • Google Chrome - Trình duyệt web và DevTools kiểm thử
  • GitHub - Nền tảng lưu trữ và cộng tác mã nguồn
  • Git - Hệ thống quản lý phiên bản phân tán
2. list-style-position: inside

Dấu đánh dấu nằm bên trong nội dung, cùng dòng với văn bản:

  • Visual Studio Code - Trình soạn thảo mã nguồn mạnh mẽ
  • Google Chrome - Trình duyệt web và DevTools kiểm thử
  • GitHub - Nền tảng lưu trữ và cộng tác mã nguồn
  • Git - Hệ thống quản lý phiên bản phân tán
Mục 6

Sử dụng thuộc tính rút gọn (list-style shorthand)

Thiết lập đồng thời kiểu đánh dấu (square), vị trí (inside) và hình ảnh (url('bullet.png')) trong một dòng CSS:

  • Kiến thức cấu trúc HTML5 ngữ nghĩa và chuẩn SEO
  • Kỹ thuật định kiểu CSS3, Flexbox và Grid Layout hiện đại
  • Lập trình xử lý DOM và sự kiện tương tác trong JavaScript
  • Quy trình làm việc Git Flow và quản lý nhánh chuyên nghiệp
Mục 7

Tạo kiểu danh sách với màu sắc và khoảng cách

Danh sách các ngôn ngữ lập trình với màu nền (background-color), màu chữ (color), khoảng đệm (padding) và lề (margin):

  • HTML - Ngôn ngữ đánh dấu siêu văn bản
  • CSS - Ngôn ngữ định kiểu tầng
  • JavaScript - Ngôn ngữ lập trình tương tác web
  • Python - Ngôn ngữ lập trình đa năng và trí tuệ nhân tạo
Mục 8 • Tổng hợp

Bài tập tổng hợp: Lộ trình học lập trình Web

Kết hợp toàn diện các kỹ thuật: kiểu đánh dấu, màu nền hiện đại, màu chữ tương phản cao, khoảng cách padding/margin tối ưu, vị trí inside và hiệu ứng hover:

  • Chặng 1 HTML - Xây dựng cấu trúc trang web vững chắc, chuẩn ngữ nghĩa W3C.
  • Chặng 2 CSS - Thiết kế giao diện thẩm mỹ, màu sắc, bố cục thích ứng (Responsive).
  • Chặng 3 JavaScript - Xử lý logic nghiệp vụ, tương tác người dùng và kết nối API.
  • Chặng 4 Git - Quản lý phiên bản mã nguồn cục bộ, commit và rẽ nhánh an toàn.
  • Chặng 5 GitHub - Lưu trữ đám mây, làm việc nhóm qua Pull Request và CI/CD.
