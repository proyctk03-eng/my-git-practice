📌 Các Bước Thực Hiện Chi Tiết

  1. Bước 1: Viết và soạn thảo kịch bản SQL

    Mở MySQL Workbench, đăng nhập tài khoản root. Nhấn biểu tượng New Query Tab (phím tắt Ctrl + T) để mở tab soạn thảo lệnh.

  2. Bước 2: Khởi tạo CSDL `demo`

    Thực thi câu lệnh tạo cơ sở dữ liệu mới và chuyển ngữ cảnh làm việc sang CSDL vừa tạo:

    SQL Query 
    CREATE DATABASE demo;
USE demo;
  3. Bước 3: Định nghĩa bảng `Student`

    Tạo bảng sinh viên gồm 4 trường với kiểu dữ liệu tương ứng:

    CREATE TABLE Student 
    CREATE TABLE Student (
    id INT,
    name VARCHAR(200),
    age INT,
    country VARCHAR(50)
);
  4. Bước 4: Thực thi và xác nhận kết quả

    Bấm biểu tượng Execute (Tia sét) hoặc Ctrl + Shift + Enter. Quan sát cửa sổ Action Output bên dưới để thấy trạng thái tích xanh 0 row(s) affected. Nhấn Refresh ở ngăn Schemas để thấy bảng Student.

🚀 2. Kịch Bản Mở Rộng Chuẩn Doanh Nghiệp (02_create_table_student_advanced.sql)

Áp dụng tiêu chuẩn Database Architect: Mã hóa utf8mb4 tiếng Việt, Khóa chính AUTO_INCREMENT, Ràng buộc CHECK/NOT NULL, Timestamp kiểm toán:

02_create_table_student_advanced.sql 
CREATE DATABASE IF NOT EXISTS demo
    CHARACTER SET utf8mb4
    COLLATE utf8mb4_unicode_ci;

USE demo;

CREATE TABLE IF NOT EXISTS Student_Advanced (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(200) NOT NULL,
    age INT NOT NULL CHECK (age >= 16 AND age <= 100),
    country VARCHAR(50) NOT NULL DEFAULT 'Vietnam',
    email VARCHAR(100) UNIQUE,
    status ENUM('Active', 'Suspended', 'Graduated') DEFAULT 'Active',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
