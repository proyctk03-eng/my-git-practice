BÀI THỰC HÀNH CSDL MYSQL WORKBENCH

Xoá Cơ Sở Dữ Liệu Trên MySQL Workbench

Thực hành 2 phương thức: Giao diện đồ họa (Drop Schema) & Câu lệnh SQL (DROP DATABASE)

⚠️ CẢNH BÁO AN TOÀN TỪ ĐỀ BÀI:
Chúng ta phải rất cẩn thận với thao tác xoá CSDL bởi vì tất cả các dữ liệu trong CSDL này sẽ bị mất nếu không được sao lưu trước đó.

🛠️ Cách 1: Xoá CSDL Bằng Giao Diện MySQL Workbench (GUI)

  1. Bật MySQL Workbench và đăng nhập bằng tài khoản root.
  2. Tại panel Navigator: SCHEMAS bên trái, chọn CSDL muốn xoá (ví dụ my_database).
  3. Click chuột phải vào CSDL và chọn Drop Schema...
  4. Hộp thoại xác nhận xuất hiện cảnh báo dữ liệu sẽ bị xoá vĩnh viễn: Chọn nút Drop Now.
  5. Kiểm tra trạng thái tại Action Output: Lệnh thực thi thành công và CSDL đã bị xoá khỏi danh sách.

⚡ Cách 2: Xoá CSDL Bằng Câu Lệnh SQL Trên Workbench

  1. Trong cửa sổ MySQL Workbench, nhấn chọn biểu tượng New Query Tab hoặc nhấn Ctrl + T.
  2. Nhập câu lệnh theo yêu cầu đề bài:
    DROP DATABASE `my_database`;
  3. Nhấn biểu tượng tia sét (Execute) hoặc tổ hợp phím Ctrl + Enter để chạy lệnh.
  4. Kiểm tra Action Output: Dấu tích xanh [OK] DROP DATABASE my_database - 0 row(s) affected.
  5. Nhấn Refresh ở mục SCHEMAS để xác nhận CSDL đã được xoá thành công!

🛡️ Mở Rộng: Quy Trình 4 Bước An Toàn Dữ Liệu (Data Safety)

Cơ chế chuyên nghiệp: Luôn sử dụng IF EXISTS và sao lưu trước khi xoá:

-- Cú pháp an toàn tránh Error 1008:
DROP DATABASE IF EXISTS `my_database`;

-- Kiểm tra lại danh sách CSDL:
SHOW DATABASES;
